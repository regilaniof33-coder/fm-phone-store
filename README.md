# 📱 FM Phone Store 
Responsive website developed for my family's mobile phone store. 
The project was created to provide an online presentation of the store and its products, while also serving as a practical project for studying web development. 
## 🚀 Technologies 
- HTML5
- CSS3 
- Git & GitHub 
- GitHub Pages
## ✨ Features 
- Responsive design
- Product presentation
- Navigation between sections
- Mobile-friendly layout
- Visual design focused on a mobile phone store
## 🌐 Live Demo [Access the website](https://regilaniof33-coder.github.io/fm-phone-store/) 
## 🎯 About the Project This is a real-world project developed for my family's mobile phone store. It was also an opportunity to practice HTML, CSS, responsive design and deploying a website using GitHub Pages.
